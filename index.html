工作流架构

      

        
① 用户输入
综艺名 · 话题词 · 方向 · 类型 · 字数 · 数量 · 剧情

        
↓

        
② 联网搜索学习
按综艺名检索节目背景 → 存入知识库

        
↓

        
③ 结构化提示词构造
角色 + 风格库 + 动态话题词 + 约束 + 格式

        
↓

        
④ 大模型调用
LLM API · 温度 / 长度控制

        
↓

        
⑤ 结果解析 & 格式化
按「文案N：」切分 · 清洗 · 结构化返回

        
↓

        
⑥ 输出
批量文案 · 结尾附 #综艺名# #话题词#

      

    

    

      
关键技术点

      
    
        
  • 联网搜索增强：综艺名自由输入，Agent 先联网检索节目背景补全知识库，再进入生成环节。
    • 
        
  • 动态话题词：结尾话题由「综艺名 + 用户话题词」动态拼装，不写死。
    • 
        
  • 可扩展知识库：综艺 / 人设均可增删，新增人设只需绑定基础语气 + 一条示例，生成逻辑零改动。
    • 
        
  • 结构化输出：约定「文案N：」格式，后端正则切分，保证可程序化处理。
    • 
      

    

  


  
  

    

      
Agent 系统提示词（节选）

      
# 角色
你是资深综艺宣发文案专家，擅长为综艺撰写微博热搜文案。

# 输入参数
1. 综艺名称(自由输入)  2. 话题词(可选)
3. 文案方向(主持人/红V/蓝V/素人，可扩展)
4. 内容类型(贴文/评论)  5. 字数(直接输入)  6. 数量  7. 剧情

# 流程
1. 若知识库无该综艺信息，先联网搜索节目背景(平台/类型/常驻/特色)
2. 按所选方向调用对应风格库(关键词 + 真实示例 few-shot)
3. 生成文案

# 写作规则
1. 每条切入角度不同、不重复
2. 严格贴合所选方向的语言风格
3. 口语化、网感强，避免 AI 翻译腔与营销感
4. 结尾统一附带话题：#综艺名# + #用户话题词#

# 输出格式
每条用「文案1：」「文案2：」…依次标注，不输出多余内容

    

    

      
风格库如何「喂」给模型

      

        
每个「账号人设」绑定：基础语气 + 风格关键词 + 真实示例文案。生成时按所选方向，把对应示例作为 few-shot 拼进提示词，让模型模仿真实爆款话术。
