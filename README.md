# 综艺热搜文案生成 Agent

> 一个自建的 AI Agent 工作流：输入一段综艺剧情与参数，自动批量产出贴合不同账号人设的微博热搜文案。

## 项目定位

面向综艺宣发场景的效率工具：当节目上热搜时，运营需要快速产出大量不同口吻（官号 / 粉丝大号 / 素人等）的微博文案。本 Agent 把「选题 → 风格适配 → 批量生成 → 格式化输出」串成一条可复用、可扩展的工作流。

## 核心能力

| 能力 | 说明 |
|---|---|
| **多账号人设适配** | 主持人 / 红V / 蓝V / 素人 四种风格，抽象为可复用风格单元 |
| **结构化提示词构造** | 角色 + 风格库 + 硬约束 + 输出格式 四段式，保证产出稳定 |
| **知识库检索增强** | 用真实爆款文案做 few-shot，锁定官方账号的话术风格 |
| **结构化输出解析** | 约定「文案N：」格式，后端正则切分清洗，结果可程序化处理 |
| **参数化控制** | 综艺、方向、类型、字数、数量、剧情 六维可控 |

## 架构

```
用户输入 → 参数解析校验 → 结构化提示词构造 → 大模型调用 → 结果解析格式化 → 输出
                              ↑
                    知识库（风格模板 + 综艺信息，few-shot 注入）
```

## 面试讲解要点（30 秒版）

> 我做了一个面向综艺宣发的 AI Agent。痛点是一档综艺上热搜时，运营需要在很短时间内产出十几条不同账号人设的微博文案——官号要克制、粉丝号要真情实感、素人要像真人。我把这些「人设」抽象成可复用的风格单元，配真实爆款文案做 few-shot，再通过结构化的提示词模板和输出格式约束，让大模型稳定地产出可直接发布的文案，而不是随机发挥。整个工作流支持六维参数控制，新增一个账号人设只需要加一条风格描述，不用改代码。

## 面试可能的追问 & 应对

**Q：为什么不直接用一句话让 ChatGPT 写？**
A：一句话提示不稳定，每次产出风格漂移、格式不统一。我把提示词工程做成结构化模板，用 few-shot 锁定风格、用输出格式约束保证可解析，这正是「从提示到 Agent 工作流」的升级点。

**Q：怎么保证生成质量稳定？**
A：三层保障——① 风格库提供真实范例做 few-shot；② 硬约束（角度不重复、措辞克制、带话题标签）；③ 结构化输出 + 后端正则解析 + 异常兜底降级。

**Q：怎么扩展新的综艺或人设？**
A：知识库与代码解耦。新增综艺只加一条节目信息，新增人设只加一条风格描述，生成逻辑零改动。

**Q：如果把大模型换成别的（换成 GPT / DeepSeek / 豆包）？**
A：生成节点是松耦合的，只要换模型参数和 API 地址即可，提示词与解析层完全复用。
