# 综艺热搜文案生成 Agent

> 一个面向综艺宣发场景的 AI Agent 工作流：输入一段剧情与参数，批量产出贴合不同账号人设的微博热搜文案。

**🔗 在线演示**：https://zzy20201212-afk.github.io/variety-show-copy-agent/

---

## 一、项目背景与痛点

综艺节目登上微博热搜时，宣发团队需要在极短时间内（通常 30 分钟到 1 小时）产出大量不同口吻的微博文案：

- **官方账号**要克制专业、措辞规范；
- **粉丝大号**要真情实感、有感染力；
- **素人号**要像真实路人随手发博。

传统做法依赖人工逐条撰写，存在三个痛点：**产量大、风格难统一、质量不稳定**。

本项目将这一重复性创作任务，抽象为一条**可复用、可扩展的 AI Agent 工作流**。

## 二、方案对比

| 痛点 | 传统方式 | 本方案 |
|---|---|---|
| 文案产量大 | 人工逐条撰写 | 批量生成，数量可配置 |
| 风格难统一 | 依赖个人经验 | 风格库 + few-shot 锁定人设 |
| 质量不稳定 | 每次临场发挥 | 结构化提示词 + 硬约束 |
| 新人上手慢 | 需要长期积累 | 参数化配置，即开即用 |

## 三、核心能力

1. **多账号人设适配**：主持人 / 红V / 蓝V / 素人 四种人设，抽象为可复用风格单元，新增人设仅需一条描述，生成逻辑零改动。
2. **联网背景检索**：综艺名称自由输入，Agent 先检索节目背景（平台 / 类型 / 常驻 / 特色）补全知识库，再进入生成环节。
3. **动态话题词**：结尾话题由「综艺名 + 用户话题词」动态拼装，不写死。
4. **结构化提示词构造**：角色 + 风格库 + 硬约束 + 输出格式 四段式，保证产出稳定。
5. **结构化输出解析**：约定「文案N：」格式，正则切分清洗，结果可程序化处理。
6. **可扩展知识库**：综艺与人设均可增删，本地持久化（localStorage）。

## 五、关键技术设计

### 1. 提示词工程（Prompt Engineering）

采用四段式结构，把「靠感觉写提示词」变成「可复用的工程模板」：

```
# 角色        → 资深综艺宣发文案专家
# 风格库      → 按人设注入对应关键词 + 真实示例
# 硬约束      → 角度不重复 / 措辞克制 / 带话题标签
# 输出格式    → 「文案N：」结构化分隔
```

### 2. Few-shot 风格锁定

每个「账号人设」绑定：**基础语气 + 风格关键词 + 2~3 条真实爆款示例**。生成时按所选人设，把对应示例作为 few-shot 拼进提示词，让模型模仿真实话术，而非凭空发挥。这是保证风格稳定、避免"AI 味"的关键。

### 3. 结构化输出约束

约定严格的输出格式，配合后端正则切分，把大模型的自然语言输出转化为**可程序化处理的结构化数据**——这是 Agent 能接入实际业务流水线的前提。

### 4. 可扩展性设计

知识库与生成逻辑**解耦**：
- 新增综艺 → 只加一条节目信息；
- 新增人设 → 只加一条风格描述；
- 换大模型 → 只改接口配置。

三处扩展均**零代码改动**。
